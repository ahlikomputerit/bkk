# BKK - Local MySQL Backend (no Docker)\n\nThis branch adds a simple Express + Prisma backend configured to use a local MySQL server (no Docker required). Follow these steps to run locally.\n\n1) Install MySQL on your machine (MySQL 8+. For macOS you can use Homebrew: `brew install mysql`).\n\n2) Start MySQL and create database and user (example commands):\n\n- Login as root (replace as needed):\n  mysql -u root -p\n\n- Run SQL:\n  CREATE DATABASE bkk;\n  CREATE USER 'bkkuser'@'localhost' IDENTIFIED BY 'bkkpassword';\n  GRANT ALL PRIVILEGES ON bkk.* TO 'bkkuser'@'localhost';\n  FLUSH PRIVILEGES;\n\n3) In the backend folder copy `.env.example` to `.env` and adjust DATABASE_URL if you changed credentials.\n\n4) Install dependencies and prepare Prisma:\n\n  cd backend\n  npm install\n  npx prisma generate\n  npx prisma migrate dev --name init\n\n5) Run the dev server:\n\n  npm run dev\n\n6) Open http://localhost:4000/api/health to verify.\n\nMigration from Supabase:\n- You can export JSON/CSV from Supabase and import into MySQL, or run a node script that reads from Supabase and upserts into MySQL via Prisma. Ask me and I can provide a migration script.\n\n---\n\nEnd of files.
